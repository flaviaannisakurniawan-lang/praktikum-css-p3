# praktikum-css-p3

Praktik CSS Pertemuan 3: penerapan **Box Model** melalui tiga kartu produk.

## Berkas

- `index.html` — struktur halaman dan tiga kartu produk.
- `style.css` — aturan box model, ukuran, padding, border, margin, dan responsivitas.

Buka `index.html` di browser, lalu gunakan DevTools untuk melihat content, padding,
border, dan margin pada elemen `.kartu-produk`.
